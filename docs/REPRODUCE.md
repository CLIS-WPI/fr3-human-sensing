# Reproducing

## Tier 0 (CPU, about a minute)
`scripts/reproduce_figures.sh` rebuilds `manuscript_numbers.json` from the shipped
per-onset miss curves (`miss_curves.npz`) and `analysis.json` (bootstrap included),
requires a match with the shipped file within 1e-9, then regenerates Figs. 1-4.

## Tier 1 (GPU, a few minutes)
`scripts/run_gates.sh` re-runs G1-G9 with Sionna 2.2 and re-evaluates G10/G11 from the
shipped production manifest; all gates must pass and G1-G9 must match the reference
within 1e-6.

## Tier 2 (GPU, about 1-1.5 h on one H100)
`scripts/run_production.sh` re-runs the production (ray tracing, analysis, numbers)
from `configs/rerun_v2.yaml`, then the controls (36-set bank, energy detector; review-2
residual-matched bank and Pfa 1e-5), and
compares every required EIRP, including the controls, with the shipped values
(tolerance 0.05 dB; the pipeline is deterministic).

Excluded from this repository: the noise-free ray-traced records (`rt_cache.npz`, regenerated by
Tier 2), earlier pipelines and their results, internal notes and the LaTeX sources.
